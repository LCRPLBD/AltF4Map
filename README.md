# AltF4Map GitHub Pages Build

This folder is ready to upload to GitHub Pages.

## Files
- `index.html` — the map page GitHub Pages will load automatically.
- `gtav-map.jpg` — the local map image used by the page.
- `.nojekyll` — prevents GitHub Pages/Jekyll processing issues.

## Upload steps
1. Open your repository: `LCRPLBD/AltF4Map`.
2. Upload these files to the repository root, not inside another folder.
3. Commit the changes.
4. Go to Settings → Pages.
5. Set Source to `Deploy from a branch`.
6. Set Branch to `main` and folder to `/root`.
7. Your page should be available at `https://lcrplbd.github.io/AltF4Map/`.

If you already have files in the repo, replace the old HTML with this `index.html` and keep `gtav-map.jpg` beside it.
